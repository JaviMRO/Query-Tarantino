# shared

Resources shared by the three implementations (Python, Java, C++), so they
all work with exactly the same data. The rules are in `SPEC.md`.

```
shared/
├── SPEC.md             # shared rules for Stage 1
├── stopwords_en.txt    # English stopwords (SPEC section 1 and 6)
└── sample_dataset/     # first 20 books of the benchmark corpus
```
